# Monthly Expense Calculator — Android APK

This is a mobile-first React + Vite expense calculator packaged with Capacitor.

## Build an APK on GitHub

1. Create a GitHub repository.
2. Upload all files from this project to the repository.
3. Push to the `main` branch.
4. Open **Actions** on GitHub.
5. Open **Build Android APK**.
6. Wait for the workflow to finish.
7. Open the completed workflow run.
8. Under **Artifacts**, download `monthly-expense-calculator-apk`.
9. Extract it and install `app-debug.apk` on Android.

You can also manually run the workflow from **Actions → Build Android APK → Run workflow**.

The generated APK is a debug APK intended for personal/testing use. A Play Store release requires a signed release build and a proper signing key.
